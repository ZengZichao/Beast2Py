Divergence times were estimated using BEAST2 v2.7.8 (Bouckaert et al. 2014). Sequence evolution for partition 'alignment' was modeled using a HKY substitution model (Hasegawa et al. 1985) with gamma-distributed rate heterogeneity (4 categories; Yang 1994). A strict molecular clock was assumed. A Yule speciation process (Yule 1925) was used as the tree prior. 1 calibration point was applied (Heled and Drummond 2012; Rieux and Balloux 2016): the MRCA of Homo_sapiens, Pan was calibrated with a LogNormal distribution (M=0.35, S=0.4) with offset 6.5 based on DOI:10.1038/nature12323 (soft boundary). MCMC chains were run for 10,000,000 generations, sampling every 1,000 generations. The analysis was configured using Beast2Py v0.1.0 (Sandve et al. 2013; Analysis Fingerprint: B2P-04ab3d09277b-0.1.0).
